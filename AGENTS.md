# Работа с wifi-vpn

- Не сохранять в Git ключи, VPN-профили, подписки, токены, пароли, SSH config,
  резервные копии и состояние конкретной установки. Примеры конфигурации
  должны использовать демонстрационные адреса и не содержать секретов.
- Изменение исходников и локальные тесты не разрешают развёртывание или
  переключение действующего домашнего трафика. Для пробного включения нужно
  явное разрешение владельца; для `gatewayctl confirm` — отдельное подтверждение
  после проверки устройств.
- Сначала сравнивать исходники с установленными файлами и сохранять настройки.
  Не применять первоначальные установщики поверх работающей сети вслепую.
- Не ставить явный `routing_mark` в рабочий AWG outbound с `auto_redirect`.
  Для проверки использовать регрессионный интеграционный стенд.
- Перед commit запускать локальные unit-тесты из README, обновлять инвентарь
  через `python3 scripts/ai_power.py inventory`, затем выполнять `check`.
- Сохранять историю удалённого репозитория; не использовать force push.
- Команды, меняющие сеть, не запускать при проверке простых изменений документации.
